# TarjetaPropuesta

Una propuesta por tarjeta: ícono, eyebrow SOMOS + tema, titular corto, dos líneas concretas y firma.

**Props:** `icon` (nombre de Icono), `eyebrow`, `titulo`, `texto`.

- El texto dice qué, dónde y cuándo. Nada de cifras sin fuente verificada en la tabla de evidencias.
- Máx. 3 tarjetas por pieza (díptico, carrusel). Cada tema de la Caja de Mensajes tiene su ícono.
