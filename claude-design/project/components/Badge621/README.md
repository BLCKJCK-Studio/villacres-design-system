# Badge621

El número de lista: aparece en TODA pieza de propaganda, correcto y legible, antes que cualquier otro adorno.

**Props:** `variant` = `horizontal` (maestro) · `vertical` · `mini`; `on` = `light` (caja `badge-bg` Selva, '1' en `oro-300`) · `dark` (caja blanca, '1' en `oro-600`); `size` = alto en px.

- ⚠ Verificar 62-1 en cada pieza. Nunca 61-1.
- El `mini` omite 'ALIANZA': úsalo solo si la palabra Alianza ya aparece en la pieza (avatar, zócalo, tarjetas).
- Tamaño mínimo: alto ≥ 48 px en un post 1080; en impreso, el '62-1' ≥ 26 mm de alto para leerse a 3 m.
- Inclinación fija de 12° (`skew`); no se gira ni se deforma. En jerarquía va tercero: rostro → nombre → 62-1.
