# Logo

El logotipo MESÍAS VILLACRÉS 2026: úsalo tal cual, desde sus archivos, y nunca lo reescribas con texto.

**Props:** `version` = `apilado` (principal) · `compacto` (sin año) · `horizontal` · `isotipo` (sol-pirámide para avatares y favicons); `color` = `full` · `negativo` · `mono-selva` · `mono-blanco` · `mono-negro`; `width` en px.

- `full` sobre `surface` crema o blanco. `negativo` sobre `selva-700`. Los monocromos son para 1 tinta: sello, serigrafía, bordado, fax.
- Área de protección: 1E por lado (E = 13,4 % del ancho del apilado). Nada entra ahí, tampoco el badge.
- Mínimos: apilado 120 px / 30 mm; compacto 96 px / 25 mm; horizontal 160 px / 40 mm; isotipo 24 px / 8 mm. Serigrafía: apilado ≥ 50 mm. Bordado: compacto mono ≥ 60 mm.
- No: deformar, recolorear, quitar el río de la S, sombras, rotar, contornear, transparencias, degradados, ponerlo sobre Verde Hoja o sobre foto sin caja.
