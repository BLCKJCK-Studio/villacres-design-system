# CheckVoto

La papeleta marcada: cuadro + visto que sobresale 12 % por arriba a la derecha, marca decidida.

**Props:** `size` (px), `on` = `light` (cuadro Selva lleno) · `dark` (cuadro blanco de contorno).

- Construcción: cuadro = 1; trazo del visto = 0,17; sobresale 0,12. El visto es siempre `vote-mark` (Lima).
- Nunca Lima sobre crema o blanco: por eso en claro el cuadro va lleno de Selva.
