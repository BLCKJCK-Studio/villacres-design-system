# Greca

La greca andina (espiral cuadrada) como fondo tono sobre tono: el tejido comunitario.

**Props:** `density` = `sutil` (6 %, módulo 60) · `media` (10 %, 40) · `protagonista` (18 %, 28); `on` = `light` · `dark` (blanco, máx. 10 %); `children`.

- Nunca detrás del rostro ni debajo de texto corrido: reserva esas zonas con un fondo liso.
- Protagonista solo en piezas sin foto (lonas, bandera, placas).
