# CtaVoto

El llamado a la acción de voto, 'VOTA 62-1' o 'MARCA 62-1', siempre con la papeleta marcada.

**Props:** `label` = `VOTA` · `MARCA`; `on` = `light` (caja Selva, texto blanco, visto Lima) · `dark` (caja Lima, texto Selva); `size` = alto en px.

- Es el único lugar, junto con CheckVoto, donde vive `voto-400`. El Lima siempre descansa sobre Selva.
- Va último en la jerarquía, uno por pieza. En la fase transicional (hasta el 11 de noviembre) el CTA es 'Cuéntame qué le falta a tu comunidad'; usa este componente solo del 12 al 26 de noviembre.
