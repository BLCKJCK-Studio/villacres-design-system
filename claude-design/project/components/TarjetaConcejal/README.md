# TarjetaConcejal

Candidatos a concejales, todos con el mismo encuadre, fondo y jerarquía, para que la plancha se lea como equipo.

**Props:** `src` (recorte), `nombre`, `apellido`, `cargo` (URBANO / RURAL), `casillero`.

- El alcalde nunca va en esta tarjeta: en fotos de plancha va al centro y adelante.
- Datos reales solo desde la lista oficial inscrita en el CNE.
