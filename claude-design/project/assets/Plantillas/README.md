# Plantillas

Vistas previas de las 20 plantillas maestras con sus guías (cian = zona editable o segura; magenta = corte o pliegue). Los SVG editables con capas FONDO / CONTENIDO / GUIAS están en el repositorio del proyecto, carpeta `plantillas/`. Las medidas y reglas de cada formato están en la sección *Formatos y retículas*.
