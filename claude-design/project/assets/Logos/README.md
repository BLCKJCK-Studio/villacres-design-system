# Logos

Logotipo MESÍAS VILLACRÉS 2026 en PNG con transparencia. Es una maqueta raster con las tildes aprobadas; el vector final se redibuja en el .ai sobre esta construcción.

- `logo-apilado-*`: principal. `logo-compacto-*`: sin año, para espacios chicos, gorras y avatares horizontales. `logo-horizontal-*`: una línea, para banners y franjas.
- `-full` sobre crema o blanco · `-negativo` sobre Selva · `-mono-selva`, `-mono-blanco`, `-mono-negro` para 1 tinta. En los monocromos el río es calado (transparente).
